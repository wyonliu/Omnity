# `packages/soap` — SOAP

**SOAP** = **S**patial **O**mnity **A**gentic **P**rotocol — 空间智能体协议（规范 + 本仓参考实现）。

## 内容规划

- `spec/` — SOAP 规范（版本化草案与 Changelog）
- `soap-scan` / `soap-sem` / `soap-edit` / `soap-render` — 工具链（随 Phase 落地）
- `soap-mcp` — 通过 MCP 暴露空间能力，便于任意 Agent 宿主接入
