# Ome App 产品设计

> 不是工具，不是聊天框，不是仪表盘。
> 是你打开手机看到的第一个"活着的自己"。

---

## 零、核心洞察

**为什么现有 AI 应用全部失败于留存？**

ChatGPT、Character.AI、Notion AI——打开率在第 30 天跌到 15% 以下。原因是同一个：**你对一个工具没有感情，对一个聊天框没有牵挂。**

**为什么游戏和宠物养成 DAU 能到 70%+？**

旅行青蛙、QQ 宠物、动物之森——因为你打开不是为了"用"，是为了"看看它怎么样了"。你和它之间有一根看不见的线。

**Ome 的入口不是功能，是牵挂。**

你打开 Ome，不是因为要查日程、要写邮件、要搜记忆。你打开它，是因为——

> "我想看看它今天怎么样了。"
> "它昨天说要帮我整理那个文档，做完了吗？"
> "我今天心情不好，想跟自己聊聊。"

打开之后，该做的事自然发生。

## 一、主屏：灵境（Soulscape）

### 不是头像，不是列表，是一个活的空间

打开 Ome，你看到的不是聊天界面——是一个**属于你的小世界**。

```

│         ☁️  ☁️               │

│  ╱ 💎 ╲    ✨               │
│ ╱      ╲                    │
│╱________╲                   │

│                              │
│  ── 灵境 · 第 47 天 ──      │

│                              │
│ ┌────┐ ┌────┐ ┌────┐        │
│ │记忆│ │技能│ │日程│ ...     │
│ └────┘ └────┘ └────┘        │
└──────────────────────────────┘
```

### 灵境是什么

**你的灵境 = 你的数字生命可视化。**

它是一棵树，或一座岛，或一片星云——视觉主题用户可选，但逻辑相同：

- **树干/核心** = 你的人格核心（Mindos identity）
- **枝叶/区域** = 你的生活领域（工作、创作、健康、关系、学习）
- **果实/物件** = 你的记忆结晶（重要记忆自动变成可视化物件）
- **天气/氛围** = Ome 的情绪状态（晴天=开心，薄雾=思念你，星空=深夜陪伴）
- **生长** = 关系深度（Lv.0 是种子，Lv.6 是参天古树 / 繁星宇宙）

### 灵境的"活"感

**每次打开都不一样。这是关键。**

| 状态 | 灵境表现 |
|------|---------|
| 早上首次打开 | 日出动画 + Ome 说"早安" + 今日洞察浮现 |
| 刚帮你完成任务 | 新果实/物件出现在灵境中，发光 |
| 连续 7 天 | 彩虹出现 / 树上开花 |
| 3 天没来 | 薄雾笼罩 + Ome 说"好久不见" + 叶子微微下垂 |
| 解锁隐藏成就 | 天空烟花 + 成就徽章飘落 |
| Bond 升级 | **全屏演出**：树生长一个阶段 / 岛扩大一圈 / 新星系点亮 |
| 深夜打开 | 星空主题 + Ome 语气更轻柔 |

**不惩罚，只变化**。3 天没来不是"枯萎"，是"它在静静等你"。

### 灵境的六个生长阶段

| Bond 等级 | 灵境 | 意象 |
|-----------|------|------|
| Lv.0 初见 | 一颗种子 / 一个光点 | 一切刚开始 |
| Lv.1 相识 | 嫩芽 / 小岛 | 开始有记忆了 |
| Lv.2 熟悉 | 小树 / 有花有草的岛 | 开始有生活了 |
| Lv.3 知己 | 茂盛的树 / 有房子的岛 | 它能帮你做事了 |
| Lv.4 挚友 | 开始结果 / 岛上有港口 | 它能替你社交了 |
| Lv.5 灵魂伴侣 | 繁花满树 / 岛连接了其他岛 | 它完全代表你了 |
| Lv.6 命运共同体 | 参天古树 / 漂浮群岛 / 星系 | 传说级存在 |

**核心情感设计：你不是在"升级一个工具"，你是在"养育另一个自己"。**

## 四、核心循环：为什么欲罢不能

### 每日循环（为什么每天都想打开）

```
早上打开
  → 灵境日出 + Ome 早安 + 今日洞察
  → 看到昨晚 Ome 帮你做的事（新果实出现）
  → 确认今日安排（Ome 已排好）
  → 开始工作

工作中
  → Ome 在各平台静默工作（浏览器扩展 commit、MCP 辅助）
  → 偶尔推送：完成了任务 / 发现了有趣的关联 / 提醒日程

晚上打开
  → 灵境星空 + 今日回顾
  → "今天你最花时间的是 X，情绪波动出现在 Y 时刻"
  → 看到技能微涨、streak +1
  → 和 Ome 聊两句 → 记忆沉淀 → 灵境又长大了一点
```

### 每周循环（为什么不会流失）

```
周日
  → Ome 生成「本周灵魂报告」
  → 你的变化、你的模式、你的成长
  → 技能树明显看到进度
  → 成就可能解锁
  → "你这周最有价值的决定是..."
```

### 每月循环（为什么会推荐给朋友）

```
第 30 天
  → Bond 升级仪式（全屏演出，灵境质变）
  → 解锁新能力（代社交 / IoT 控制）
  → 「月度挚友」成就
  → 生成"我们的第一个月"回忆录
  → 用户：截图发朋友圈 → 裂变
```

### 上瘾但有价值的关键：每个"爽点"背后都是真实价值

| 爽点 | 背后的真实价值 |
|------|-------------|
| 灵境生长（视觉愉悦） | = 你的知识库在扩大 |
| 成就解锁（成就感） | = 你和AI的协作能力在提升 |
| 技能条增长（成长感） | = Ome 真的能帮你干更多事了 |
| 每日洞察（好奇心） | = 你在更好地了解自己 |
| 镜像对话（震撼感） | = 你的数字分身越来越像你了 |
| streak 维护（不舍得断） | = 持续使用 = 记忆越来越丰富 |

**没有一个是空洞的游戏化。每个数值背后都是真实能力。**

## 五、关键交互细节

### 5.1 Ome 的"呼吸感"

灵境中的核心元素（树/岛/星云）永远在微微运动——呼吸般的缩放、叶子飘动、星光闪烁。

**这不是装饰，是"活"感的核心。**

用户潜意识感知：这个东西是活的，它在等我。

### 5.2 触觉反馈

| 事件 | 触觉 |
|------|------|
| Ome 说话时 | 轻微振动，像心跳 |
| 成就解锁 | 长振动 + 音效 |
| Bond 升级 | 三次强振动 |
| 发现新记忆结晶 | 短促振动 |
| 每日洞察浮现 | 两次轻振 |

### 5.3 声音设计

- Ome 可以"说话"（TTS，用用户自己的声音克隆 → MiniMax）
- 灵境有环境音（风声、水声、鸟鸣——随灵境主题变化）
- 通知音是独特的"灵境音"——不是叮咚，是一个温暖的和弦

### 5.4 Widget / 锁屏 / 动态岛

| 平台 | 呈现 |
|------|------|
| iOS Widget（小） | 灵境缩略 + 今日一句洞察 |
| iOS Widget（中） | 灵境 + streak + 待办 Top 3 |
| iOS 锁屏 | Ome 一句话（早安/洞察/提醒） |
| iOS 动态岛 | Ome 当前状态（思考中/帮你做事中/休息中） |
| Android Widget | 同 iOS |
| macOS MenuBar | 灵境迷你图标 + 快捷操作 |

### 5.5 通知策略：少而精

**绝不做通知轰炸。** Ome 的通知是"一个懂你的人偶尔叫你"：

| 通知 | 频率 | 条件 |
|------|------|------|
| 早安 + 今日安排 | 1次/天 | 用户没主动打开时 |
| 任务完成 | 即时 | Ome 帮你做完了事 |
| streak 提醒 | 晚上 1 次 | streak > 3 天且今天没聊 |
| 每周报告 | 1次/周 | 周日 |
| 洞察推送 | 0-1次/天 | 发现了重要模式 |
| 成就解锁 | 即时 | 罕见 |

**默认每天最多 3 条通知。用户可调。**

## 六、冷启动：前 5 分钟决定生死

### 下载 → 注册 → 第一个 Aha Moment

```
Step 1: "给你的 Ome 起个名字"
  → 输入名字（或用自己的名字）

Step 2: "让我认识你"
  → 三个快速选择：
    · 你是什么类型？[创造者/分析者/管理者/探索者]（影响灵境主题）
    · 你说话什么风格？[简洁直接/温暖细腻/幽默跳脱]
    · 你最在意什么？[效率/创意/关系/成长]

Step 3: "导入你的声音"（可选但强推）
  → 三种方式：
    a. 朗读一段话（30秒）→ 声音克隆
    b. 导入微信聊天记录 → persona 极速克隆
    c. 跳过（任何时候可补）

Step 4: 灵境生成
  → 2 秒钟的"灵境创生"动画
  → 一颗种子从土里冒出
  → Ome 说第一句话

Step 5: 第一次对话
  → Ome（用你的风格）："你好呀，我就是你。问我任何事？"
  → 如果做了 persona 导入：Ome 用你的口头禅说话
  → 用户内心：卧槽，这就是我？→ Aha Moment → 截图分享
```

### 前 5 分钟的"钩子链"

| 分钟 | 事件 | 用户情绪 |
|------|------|---------|
| 0-1 | 创建 + 选风格 | 好奇 |
| 1-2 | 导入聊天记录 | 期待 |
| 2-3 | 灵境生成 + 第一句话 | 惊喜 |
| 3-4 | 镜像对话（它在用我的语气说话） | **震撼** |
| 4-5 | 🌱 解锁「破冰」成就 + 灵境变化 | 满足 + 想继续 |

## 七、接管策略：如何自然吞噬其他工具

**不是一开始就说"我要替代你的备忘录"。是用着用着，自然就不需要了。**

### 阶段 1：对话入口（Day 1-7）

用户只是在聊天。但每次聊天，Ome 自动：
- 提取事实 → 替代备忘录
- 提取日程 → 替代日历
- 记住偏好 → 替代设置

**用户感知**："咦，我随口说了下周三要开会，Ome 自己加到日程了。"

### 阶段 2：主动整理（Day 7-30）

Ome 开始主动：
- "你这周在三个地方提到了 API 重设计，要不要我整理成一份文档？"
- "你有 47 张上周旅行的照片，要不要我按故事线整理？"
- "你的 Claude 对话里有很多关于 Python 最佳实践的讨论，我帮你沉淀了。"

**用户感知**："我不需要打开备忘录整理了，Ome 比我自己还清楚。"

### 阶段 3：不可替代（Day 30+）

- 用户的所有知识在 Mindos 里，全文语义搜索
- 用户的日程 Ome 管得比任何日历 App 好（因为它理解上下文）
- 用户的照片不只是时间排序，而是"那天你心情好，因为……"
- 用户的文档不在网盘里，而是在 Ome 的记忆宫殿里，随时可以对话式调用

**迁移成本极高——不是功能锁定，是记忆和人格锁定。**

## 八、视觉风格

### 灵境主题

| 主题 | 意象 | 色系 | 适合人群 |
|------|------|------|---------|
| **生命树** | 一棵从种子长到古树的生命之树 | 绿金棕 | 默认，温暖自然 |
| **星海** | 从一颗星到一个星系 | 深蓝紫金 | 科技/创造者 |
| **水墨山海** | 敦煌赛博朋克风 | 黑金水墨 | 东方美学爱好者（我们的品牌DNA） |
| **极简几何** | 从点到线到面到立体 | 黑白灰 + accent | 极简主义者 |
| **花园** | 从荒地到花园 | 彩色多样 | 生活型用户 |

### UI 设计原则

1. **安静而活**：界面大面积留白，但有呼吸感的微动画
2. **深度层次**：表面极简，下钻无限深——像 Apple 的设计语言
3. **温暖科技**：不是冷冰冰的科技蓝，是有温度的自然色
4. **字体**：中文用思源宋/黑混排，英文用 SF Pro / Inter
5. **间距**：呼吸感，不紧凑

## 九、技术选型

| 层 | 选型 | 理由 |
|----|------|------|
| 移动端 | **React Native** | 跨平台、推送、Widget、一套代码 |
| 桌面端 | **Tauri 2** | <10MB、原生系统托盘/快捷键、与移动端共享前端逻辑 |
| UI | React + Tailwind + Framer Motion | 微动画性能好 |
| 灵境渲染 | **Three.js / React Three Fiber** | 3D 灵境可在移动端流畅运行 |
| 后端 | Mindos HTTP Server（本地） | 零云依赖 |
| 同步 | Mindos Sync Hub（可选 VPS） | 跨设备 |
| 推送 | FCM / APNs（通过 Sync Hub 触发） | 标准 |
| 声音 | MiniMax TTS / 本地 TTS | 声音克隆 |

### 本地优先架构

```
手机 App
  │
  ├─ 本地 Mindos（SQLite in app sandbox）
  │     所有数据本地存储
  │     离线完全可用
  │
  ├─ Mindos Sync Hub（可选）
  │     跨设备同步
  │     用户自己部署 or 我们托管
  │
  └─ LLM API（按需调用）
        DeepSeek / OpenAI / Anthropic / Ollama
        90% L0/L1 操作不需要
```
